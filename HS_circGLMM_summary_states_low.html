Details

DESCRIPTION

Load and plot the state-switching circular GLMM fitted in HS_circGLMM_states.ipynb, which assigns each dance to a forward, reversed or axial (bimodal) state and models the probability of each state as a function of condition. The analysis to summarise is set by params: the solar elevation (low), the direction prior (bounded) and the model (three_states_condition), read from params$model_dir.

INPUTS

HS_functions.R, 0Data/hs_dance_states_<elevation>.feather, 2Results/state_models/HS_states_<elevation>_<direction_prior>_*.nc

OUTPUTS

Plotted estimates, predictions and contrasts.

Motivation

On a horizontal comb, and under some skylight conditions, honeybee dances are not always oriented in a single direction relative to the feeder: some dances point away from the feeder (reversed), and others alternate between two opposite directions (axial). Rather than describing these by a continuous mixture weight, each dance is assigned to one of three latent states:

state density of each waggle run
forward \(\mathcal{M}(\theta \mid \mu_d, \kappa_d)\)
reversed \(\mathcal{M}(\theta \mid \mu_d + \pi, \kappa_d)\)
axial \(w\,\mathcal{M}(\theta \mid \mu_d, \kappa_d) + (1-w)\,\mathcal{M}(\theta \mid \mu_d + \pi, \kappa_d)\), \(0.25 < w < 0.75\)

The probability of each state is modelled with a multinomial logit (forward as reference), with condition effects and individual random effects:

\(\log(\pi_\text{reversed} / \pi_\text{forward}) \sim\) condition + (1 |Individual)

\(\log(\pi_\text{axial} / \pi_\text{forward}) \sim\) condition + (1 |Individual)

The forward direction of each dance, \(\mu_d\), combines a direction for its condition with individual and dance offsets, and the concentration, \(\kappa_d\), has condition effects and individual and dance random effects. Condition effects are coded as successive differences, vertical → horizontal → antisolar → solar (H, A, S), as in HS_circGLMM_fit_4cond.ipynb. To keep reversals from being described by 180° changes in direction, condition directions and dance offsets are bounded (see HS_circGLMM_states.ipynb), and individual offsets have a strongly concentrated von Mises prior (\(\kappa_u \sim \text{LogNormal}(\log 30, 0.6)\)). Chains that settled in poor local optima (mean log posterior more than 20 below the best chain) were dropped before saving.

This loads draws from the fitted model’s posterior distribution, using the reticulate package to read the Python arviz file. Draws = function(name)
{
  vals = reticulate::py_get_item(post, name)$values
  d = dim(vals)
  if(length(d) == 2)
  {
    as.vector(t(vals))
  }else if(length(d) == 3)
  {
    matrix(aperm(vals, c(2, 1, 3)), ncol = d[3])
  }else
  {
    array(aperm(vals, c(2, 1, 3, 4)), dim = c(n_samp, d[3], d[4]))
  }
}

Extract predictions

The posterior is summarised by its median and central \(95\%\) interval. For circular quantities, draws are centred on their circular median before calculating quantiles, so that the boundary falls far from the bulk of the estimates.

#A function to find the circular median in (-pi, pi)
MedCDraws = function(x,
                     templ = 'none', #assumes radians
                     medn = 1) #take the 1st median
{
  median.circular( circular(x = mod_circular(x),
                            template = templ)
                                           )[medn]
}
#A function to report circular quantiles in degrees, centred on the circular median
QDegDraws = function(x,
                     probs = c(0.5, 0.025, 0.975))
{
  mx = as.numeric(MedCDraws(x))
  round(deg(
    quantile(mod_circular(x - mx), probs = probs) + mx
  ))
}
#A function to report linear quantiles
QDraws = function(x,
                  probs = c(0.5, 0.025, 0.975),
                  digits = 2)
{
  round(quantile(x, probs = probs),
        digits = digits)
}
#Bounded offset, as in the model (B*tanh(x/B))
Bounded = function(x, bound = pi/3)
{
  bound * tanh(x / bound)
}
#Condition design: which successive effects apply to each condition
XCond = function(cnd){as.numeric(effect_names %in% cond_effs[[cnd]])}
#Population concentration for a condition
KappaCond = function(cnd)
{
  eta = kappa0
  if(length(effect_names)){eta = eta + kappa_eff %*% XCond(cnd)}
  softplus(as.vector(eta))
}
#State probabilities for a condition, optionally for an individual: samples x states
StateProbs = function(cnd, i = NULL)
{
  eta = sapply(model_states,
               function(s)
               {
                 if(s == 'forward'){return(rep(0, n_samp))}
                 e = state_int[[s]]
                 if(!is.null(state_eff[[s]])){e = e + as.vector(state_eff[[s]] %*% XCond(cnd))}
                 if(!is.null(i)){e = e + ind_state_z[[s]][, i + 1]}
                 e
               })
  exp(eta - apply(eta, 1, max)) / rowSums(exp(eta - apply(eta, 1, max)))
}
#Expected weight of the forward direction (mu1) in a dance, given its state probabilities:
#forward dances put all runs at mu1, axial dances a proportion w, reversed dances none
WForward = function(ps)
{
  ps[, 'forward'] + if('axial' %in% colnames(ps)){w_axial * ps[, 'axial']}else{0}
}

Population-level predictions for each condition

For a typical individual (individual effects at zero): the forward direction (\(\mu_1\), with the reverse direction \(\mu_2 = \mu_1 + 180°\)), concentration (\(\kappa\), and mean vector length \(\rho = A_1(\kappa)\)), the probability of each state, and the expected proportion of waggle runs towards \(\mu_1\), \(w_1 = \pi_\text{forward} + w\,\pi_\text{axial}\).

pop_draws = lapply(setNames(conds, conds),
                   function(cnd)
                   {
                     ps = StateProbs(cnd)
                     colnames(ps) = model_states
                     list(mu = mu_cond[, cnd],
                          kappa = KappaCond(cnd),
                          p = ps,
                          w1 = WForward(ps))
                   })

Visualising individual predictions

For each bee in each condition: the observed waggle runs, density contours for the population-level mean vector of each mode in that condition (forward mode in red-yellow, reverse mode in blue, opacity scaled by its weight), thin lines for each dance’s two modes, and arrows for the individual’s two modes. Each mode is drawn with length \(A_1(\kappa)\) and line width scaled by its weight (\(w_1\) and \(1 - w_1\)), following PlotMV_circMLE, with a minimum width of 0.5 so that minor modes remain visible; opacity is also scaled by weight (minimum 25%), so that many overlapping minor modes do not look like a major one.

#Plot separate mean vectors for each mode (mu1 and mu1 + pi), each of length A1(kappa),
#with line width scaled by the weight of that mode (as in PlotMV_circMLE: lwd = 5 * weight1)
ModeArrows = function(mu, kappa, w1, col, lwd = 5, lwd_min = 0.5, length = 0, alpha = 200/255)
{
  mus = c(mu, mod_circular(mu + pi))
  ws = c(w1, 1 - w1)
  for(md in 1:2)
  {
    arrows.circular(
      x = circular(mus[md], units = 'radians', rotation = 'clock', zero = pi/2),
      y = A1(kappa),
      lwd = max(lwd_min, lwd * ws[md]),
      length = length,
      #fade minor modes too, so that overlapping thin lines do not look like a major mode
      col = adjustcolor(col, alpha.f = alpha * max(0.25, ws[md]))
    )
  }
}
#Posterior density contours for the mean vector of each mode, opacity scaled by its weight
ModeContours = function(mu, kappa, w1)
{
  dl = list(mu = mu, kappa = kappa)
  w_med = median(w1)
  Draws2Cont(dl, alpha = 200/255 * w_med,
             x_string = 'sin(mu) * A1(kappa)', y_string = 'cos(mu) * A1(kappa)')
  Draws2Cont(dl, palette = 'Blues 3', alpha = 200/255 * (1 - w_med),
             x_string = '-sin(mu) * A1(kappa)', y_string = '-cos(mu) * A1(kappa)')
}
